# 🛒 Sistema de Ventas - Examen Técnico

Este es un proyecto de gestión de ventas desarrollado, utilizando **.NET Core** para el Backend y **React** para el Frontend.

---

## 🚀 Estructura del Proyecto

El repositorio está organizado de la siguiente manera:

* **`/backend`**: API desarrollada en .NET con Entity Framework y SQL Server.
* **`/frontend`**: Aplicación web desarrollada con React, Vite y Axios para el consumo de la API.
* **`/database`**: Scripts y archivos relacionados con la base de datos SQL.
* **`/docs`**: Scripts para postman JSON.
---

## 🛠️ Tecnologías Utilizadas

### Backend
* **.NET Core / ASP.NET Web API**
* **SQL Server** (Base de datos)
* **Inyección de Dependencias** y Patrón Repository.

### Frontend
* **React** (Vite)
* **React Router Dom** (Navegación)
* **Axios** (Peticiones HTTP)

---
